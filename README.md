# Многокритериальная модель адаптивного обучения

## Описание

Разработка алгоритма многокритериального принятия решений для формирования
индивидуальных образовательных траекторий специалистов промышленных предприятий.

## Структура репозитория

- `src/` — исходный код
- `data/` — данные
- `models/` — результаты работы модели и веса
- `results/` — результаты экспериментов

## Требования

- Python 3.10
- NumPy 1.26
- Pandas 2.3
- SciPy 1.15
- Matplotlib 3.10
- torch 2.5
- scikit-learn 1.7
- seaborn 0.13

## Установка

```bash
pip install -r requirements.txt
```
